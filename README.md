# 智能剪辑（AIClip）

这是一个可以在 iPhone 上本地编译、安装的最小可用视频剪辑应用。它支持从相册导入视频、手动剪辑、滤镜与字幕、导出回相册，并通过一套可插拔的 AI 接口，把自然语言指令转成结构化的剪辑操作后执行。

它不是完整的剪映 / CapCut 替代品，也不包含上架 App Store 的流程。本说明只覆盖用你自己的 Mac 和 Xcode，把应用装到模拟器或真机。

## 打开工程

1. 把 `AIClip.zip` 解压到任意目录（例如「下载」或「开发」文件夹）。
2. 用 Xcode 打开解压后的 `AIClip/AIClip.xcodeproj`，不要打开单个 `.swift` 文件。
3. 左侧应能看到 `AIClip` 目标，以及 `Models`、`Editor`、`Effects`、`AI`、`UI` 等分组。

建议使用当前正式版 Xcode（Xcode 15 或更高，以支持 iOS 17 部署目标）。

## 设置签名并安装

1. 在 Xcode 项目导航里点选最上方的蓝色 `AIClip` 工程，再选中 `AIClip` 目标。
2. 打开 **Signing & Capabilities**。
3. 勾选 **Automatically manage signing**。
4. 在 **Team** 里选择你的 Apple ID 开发团队。工程里的 Team 是空的，需要由你来指定。
5. 确认 Bundle Identifier 为 `com.yanz.aiclip`。如果这个 ID 在你的账号下已被占用，可以改成你自己的唯一 ID，但不要改包名以外的工程结构。

### 在模拟器中运行

1. 在 Xcode 顶部方案旁选择一台 iOS 17 或更高的 iPhone 模拟器。
2. 按 **Command-R** 或点运行。
3. 模拟器里可以用照片 App 中的示例视频，或把视频拖进模拟器相册后再到「智能剪辑」里导入。

### 安装到 iPhone

1. 用数据线连接 iPhone，并在手机上如有提示时选择「信任这台电脑」。
2. 在 Xcode 顶部设备列表里选择你的 iPhone。
3. 按 **Command-R** 运行。第一次在真机安装时，可能需要在 iPhone 的 **设置 → 通用 → VPN 与设备管理**（或「设备管理」）里信任你的开发者证书，然后再打开应用。
4. 免费个人团队的应用通常有 7 天签名有效期，过期后需要用 Xcode 重新运行一次。

## 权限说明

- 从相册**导入**视频使用系统的 PHPicker，一般不需要完整相册读取权限。
- **导出**到相册时，系统会请求添加照片权限。请选择允许。如果误点拒绝，请到 **设置 → 隐私与安全性 → 照片 → 智能剪辑** 中打开「添加照片」权限。
- 应用在 Info.plist 和 Xcode 构建设置里都声明了：
  - `NSPhotoLibraryUsageDescription`：智能剪辑需要访问相册，以便导入视频进行剪辑。
  - `NSPhotoLibraryAddUsageDescription`：智能剪辑需要将导出的视频保存到你的相册。

## 配置 AI 接口

应用默认开启 **演示模式**：不会发起网络请求，也不需要 API 密钥。演示模式用本地规则解析若干常见中文指令（例如「去掉开头 3 秒，加上淡入，并在底部加字幕」），并明确标注这不是实时模型回复。

若要接入真实模型：

1. 打开应用内 **设置**，关闭「演示模式」。
2. 填写 API 地址、模型名称和 API 密钥。密钥保存在本机钥匙串中，没有写进源代码。
3. 若使用 OpenAI 兼容的 Chat Completions 接口，保持该开关开启，并把地址填到 `/v1` 这一级，例如 `https://api.openai.com/v1`。应用会请求 `/chat/completions`，系统提示会要求模型**只返回** `AIEditSchema.md` 中定义的 JSON。
4. 若关闭兼容模式，应用会把 `{ schemaVersion, instruction, context }` 直接 POST 到你填写的完整地址，并期望响应为同一套 schema 的 JSON。

系统提示、字段含义和示例见仓库中的 [AIEditSchema.md](AIEditSchema.md)。

## 这个 MVP 里已经可以工作的功能

- 从相册导入视频（可替换当前项目，或追加到时间线）。
- 预览播放、时间线与播放头，点击或拖动时间线可定位。
- 手动剪辑：设置入点 / 出点、在播放头处分割、删除选中片段、调整倍速（0.25× 到 4×）。
- 特效：原片、鲜艳、黑白、暖色、冷色、复古、电影共 7 种颜色滤镜；可输入文本的字幕（位置、开始时间、持续时长、字号）；淡入 / 淡出。
- 将合成结果通过 `AVAssetExportSession` 导出到相册。
- AI 剪辑面板：把当前时间线元数据和自然语言指令交给可插拔后端（或演示模式解析器），校验 JSON 决策列表后应用到时间线。
- 撤销上一步编辑。

## 限制

- 这不是完整的专业剪辑工具，没有多轨道自由编排、关键帧动画、转场库、美颜、贴纸商店、自动卡点或复杂调色曲线。
- 字幕和淡入淡出按项目时间线定位；大幅度改速度或大幅裁剪后，已有字幕的时间可能需要再调一次。
- 倍速会同时缩放音频，没有独立变调补偿以外的精细控制（导出预览使用了系统的时间音高算法）。
- 演示模式只能识别文档和面板里列出的那类指令，不会假装自己是在线大模型。
- 工程不持久化未导出的项目；杀掉应用后，需要重新导入视频。已复制到应用沙盒的视频文件可能仍留在设备上，但时间线不会自动恢复。
- 超长、超高分辨率或 HDR 视频可能占用较多内存，或在自定义合成器中被按标准色彩处理。
- 本仓库不包含 App Store Connect、证书、截图或审核材料，只支持用 Xcode 本地安装。
